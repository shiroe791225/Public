# TOEIC 600 單字

多益 600 分核心單字學習網站：間隔重複單字卡、測驗、發音、進度追蹤。純靜態網頁，無需安裝或後端。

## 多益 600 分需要多少單字？

| 項目 | 數量 | 說明 |
|---|---|---|
| 總詞彙量 | **約 3,000–4,000 字** | 含國高中基礎字，能讀懂大部分題目 |
| 多益情境高頻字 | **約 2,000 字** | 辦公、人事、財務、採購、旅遊等商務情境 |
| 本站收錄 | **1,253 字** | 最高頻核心字，分 12 主題、3 等級 |

等級對應：Lv1 基礎（~450 分）→ Lv2 核心（~550 分）→ Lv3 進階（600+）。

> 單字量是必要條件，不是充分條件。600 分還需要聽力（Part 1–4）與文法題型（Part 5–6）練習。

## 功能

- **背單字**：SM-2 間隔重複（忘記 / 困難 / 記得 / 簡單），自動安排複習日；可依主題學習
- **測驗**：英→中、中→英、例句填空（模擬 Part 5）；答錯自動排入複習
- **字庫**：搜尋、依主題 / 等級 / 狀態篩選、標記難字
- **發音**：瀏覽器內建語音（Web Speech API），可調語速
- **進度**：存在瀏覽器 localStorage；設定頁可匯出 / 匯入 JSON 備份

快捷鍵：空白鍵翻面、1–4 評分 / 選答案、P 發音、Enter 下一題。

## 建議學習 SOP

1. 每天 **20 個新字**（約 15–20 分鐘），先清完「待複習」再學新字
2. 評分要誠實：想不起中文就按「忘記」
3. 每週做 1–2 次測驗（範圍選「已學過的字」），錯題自動回到複習
4. 約 **9 週**學完 1,253 字；之後持續每日複習直到多數字變「熟記」（間隔 ≥ 21 天）

## 使用方式

- **本機**：下載 repo，直接用瀏覽器開啟 `index.html`
- **GitHub Pages**：合併到 `main` 後，到 repo **Settings → Pages → Source 選 GitHub Actions**，`.github/workflows/pages.yml` 會自動部署
  - 注意：私人 repo 啟用 Pages 需 GitHub Pro / Team 以上方案；Free 方案需將 repo 設為公開

## 擴充單字

單字依主題放在 `data/wNN-*.js`，每行一字：

```
等級|單字|詞性|中文|英文例句（用 *星號* 標出目標字）|例句中文
2|invoice|n.|發票；請款單|Please send us an *invoice* for the work.|請寄給我們這次工作的請款單。
```

重複的單字會自動略過。新增主題請在 `data/topics.js` 的 `TOPICS` 加一筆，並在 `index.html` 引入檔案。
