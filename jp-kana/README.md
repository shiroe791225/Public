# 五十音 稽古帖

平假名與片假名共 104 音的學習工具。純靜態網頁，無後端。

## 四個分頁

| 分頁 | 內容 |
|---|---|
| 五十音表 | 可點選的字表，切換「平假名／片假名／對照」與「清音 46／濁音半濁音 25／拗音 33」。格子底色＝熟練度熱圖 |
| 課程 | 16 課：あ行〜わ行（10 課）→ 濁音 2 課 → 拗音 → 長音促音規則 → 片假名外来語 24 字 → 易混字 14 組 |
| 練習 | 7 種題型 × 5 種範圍 × 10/20/40 題自由組合 |
| 進度 | 熟練數、到期複習、最常錯的假名、語速、深淺色、備份 |

題型：看平假名選音、看片假名選音、看羅馬字選平假名、看羅馬字選片假名、平↔片互換、聽音選假名。

## 設計重點

- **字卡附字源**：あ←安、ア←阿、ニ←二、ロ←口。片假名幾乎都是漢字的一部分，知道來源比硬背快。
- **每課單字只用已教過的假名**。L2 只會出現あ行＋か行的字（かお、かく、きく、いけ、こえ）。這項規則由建置時的檢查程式逐課驗證。
- **同音陷阱已處理**：お／を、じ／ぢ、ず／づ 讀音相同，因此自動排除於「由音選字」與「聽音」題型，不會出現兩個都正確的題目。
- **色碼帶資訊**：平假名＝藍鉄，片假名＝弁柄，全站一致。
- 字體使用 Klee One（教科書體），筆形接近手寫範本。

## 建議用法

| 情況 | 走法 |
|---|---|
| 從零開始 | 課程 L1→L16 依序，每天 2〜3 課，約兩週完成 |
| 已有基礎、只補強 | 直接做 L16 易混字特訓 ＋ L15 外来語，再用「練習」選「看片假名→選音」「我的弱點」各 40 題 |

常見弱點集中在 **シ／ツ、ソ／ン、ク／タ／ワ** 與片假名長音「ー」。

## 限制

- 沒有筆順動畫，只有筆畫數與文字提示。要練手寫請搭配方格紙。
- 發音為瀏覽器語音合成，長音／促音的拍子感比真人弱。
- 沒有日文語音的裝置，「聽音選假名」會自動停用。

## 進度儲存

存在瀏覽器 localStorage。換裝置前到**進度 → 備份 → 產生備份碼**保存 JSON，新裝置用「從備份碼還原」貼回。
