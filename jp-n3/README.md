# 通勤 N3 道場

從 N4 到日檢 N3 的 12 週課程，針對**每天 40 分鐘通勤時間**設計。純靜態網頁，無後端。

## 課程結構

| 項目 | 設計 |
|---|---|
| 長度 | 12 週 / 84 天（每 7 天一個複習日，共 12 個） |
| 每日 | 4 × 10 分鐘區塊＝40 分鐘，每區塊附倒數計時（點計時器可暫停） |
| 一般日 | ① 語彙 8 字 → ② 文法 1〜2 項 → ③ 漢字／読解／聴解（輪替）→ ④ 到期卡片複習 |
| 複習日 | 弱點複習 12 分 ＋ 聴解 8 分 ＋ 20 題迷你模擬 20 分 |
| 進度推進 | 按「天」而非日曆：中斷直接關掉，隔天從未完成的區塊接續 |
| 複習排程 | 間隔 1-2-4-8-16-32-64 天；答錯退回第 1 階，隔天重出 |

## 收錄內容

| 類型 | 數量 | 檔案 |
|---|---|---|
| 單字 | 576（72 主題組 × 8） | `data/vocab_a.js`、`data/vocab_b.js` |
| 文法 | 100 項（接續＋中文＋易混重點＋2 例句） | `data/grammar.js` |
| 漢字 | 160 字（40 組，音訓讀＋例詞） | `data/kanji.js` |
| 読解 | 18 篇（短文／中文／情報検索＋解析） | `data/reading.js` |
| 聴解 | 30 題（對話稿＋題目＋中文大意） | `data/listening.js` |

84 天的課程表會完整覆蓋以上全部內容，沒有遺漏或重複；字庫搜尋可查全部 836 個項目。

## 限制

- **單字量不足以單靠本站過 N3**。N3 實考語彙量約 1,500〜2,000，這裡是高頻核心 576 字，建議搭配市售單字書或 Anki 牌組。
- **聴解是瀏覽器語音合成，不是真人音檔**。適合練理解與跟讀，不適合當正式模擬聽力；考前請用官方《公式問題集》真音檔。
- 沒有日文語音的裝置，聴解區塊會自動改為「讀稿模式」。

## 進度儲存

存在瀏覽器 localStorage。換裝置或清除瀏覽器資料前，到**設定 → 備份 → 產生備份碼**，把 JSON 存起來，新裝置用「從備份碼還原」貼回去。

## 檔案

```
index.html      版面與樣式
app.js          課程表、測驗、間隔複習、朗讀
data/*.js       內容（各自掛在 window.N3_* 上）
```

新增單字：在 `data/vocab_*.js` 的陣列尾端加主題組（每組 8 字），課程表會自動把新組排進去。
